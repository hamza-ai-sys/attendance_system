# Contributing

The canonical contribution instructions are in [docs/development/contributing.md](docs/development/contributing.md).

Before opening a pull request:

- follow the [testing requirements](docs/development/testing.md);
- follow the [database change workflow](docs/development/database-changes.md) when applicable;
- record qualifying architecture decisions under [docs/architecture/decisions](docs/architecture/decisions/README.md); and
- complete the pull request template.

AI-assisted development is welcome, but the contributor remains responsible for correctness, security, tests, and documentation.
