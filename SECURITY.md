# Security Policy

Security requirements are maintained in two places:

- [Secure development](docs/development/security.md) — coding, secrets, data access, authentication, devices, and reporting
- [Deployment security](docs/deployment/security.md) — production configuration, transport, access, monitoring, backups, and incident readiness

Report suspected vulnerabilities privately to the repository owner or designated security contact. Do not publish sensitive details in a public issue.
